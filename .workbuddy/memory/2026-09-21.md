## 2026-09-21 追加3：透明窗口下 antd 弹窗不可见/遮罩残留（重要坑）
- **根因**：macOS 透明窗口（macOSPrivateApi + transparent）下 WKWebView 合成层渲染 bug——带 CSS 动画/transform 的悬浮层（antd Modal 的 zoom 动画、mask 的 fade 动画）不绘制：打开弹窗只见遮罩不见内容，关闭动画卡住导致遮罩 DOM 残留、全局无法点击。
- **修复**（style.css）：全局禁用 antd 过渡动画类 `[class*='-enter-prepare'/-enter-start'/-enter-active'/-leave-active'] { animation:none!important; transition:none!important; opacity:1!important; transform:none!important; }`，浮层立即呈现最终状态。对 Popover/Select 下拉等所有 antd 浮层同样生效。
- 附带：为复现问题安装了 agent-browser（npm 全局）+ Chromium（~/.agent-browser），纯浏览器跑本项目会因 scheduleManager 顶层初始化 Tauri SQL 失败而白屏，浏览器复现 Tauri 应用不可行。

## 2026-09-21 追加4：弹窗灰屏真正根因（重要教训）
- **真根因**：RightPanel 引用了 `weatherManager.getSupportedDays()`，但 weatherManager.js 里该方法及 `maxDays` 字段从未成功落盘（编辑丢失，与之前卡片头部刷新按钮丢失同因）。弹窗渲染时 computed 抛 TypeError → antd Modal 对话框子树渲染崩溃、遮罩已挂载 → 灰屏+残留遮挡全局点击。之前"7天点击没反应"也是同一根因（切换触发 computed 重算抛错冻结 UI）。
- **教训 1**：渲染期 JS 异常会导致 antd-vue Modal 半挂载（mask 在、dialog 崩），表现为"灰屏+点击全死"，排查时先查渲染链路上的未定义函数/属性，不要先怀疑渲染层。
- **教训 2**：本环境多次出现 Edit 报告成功但内容未落盘/被回滚的现象。凡涉及跨文件多轮编辑，收尾必须用 grep 对所有新增标识符做"引用↔定义"闭环复查（本次靠 `/usr/bin/grep -n "getSupportedDays" weatherManager.js` 空结果定位）。
- 修复后已全量闭环复查 RightPanel/weatherManager 所有标识符；style.css 的 antd 动画禁用规则保留作透明窗口防御（无副作用，仅弹窗无动画）。

## 弃用 window-state 插件，手写窗口状态记忆（重要）

- 症状：退出重开窗口错乱（重影/巨大化），再重开又正常；自启动后窗口"消失"，Dock/状态栏点击都打不开。
- 根因：`tauri-plugin-window-state` v2.4.1 在 Retina 上物理/逻辑像素混用：存的是 outer_size 物理像素（900×562→1800×1124），按逻辑像素恢复 → 尺寸翻倍、位置 x=1410 超出 1512 宽屏幕 → 窗口在屏幕外"看不见"，`has_visible_windows=true` 导致 Reopen 不处理、show() 无效果。
- 修复：移除插件，`lib.rs` 手写 `save_win_state`/`restore_win_state`：逻辑像素存取（outer_size/scale_factor），存 `win-state.json`（app_config_dir）；恢复时校验位置在当前屏幕内否则 `center()`；最大化时只存 maximized 标记不覆盖尺寸。保存时机：`CloseRequested` + `RunEvent::ExitRequested`（覆盖 Cmd+Q）。
- 教训：Tauri 存窗口位置必须校验"目标位置仍在当前显示器内"，防止外接屏拔掉后窗口丢失。

## WorkBuddy 沙箱环境打 DMG 的坑（环境问题，非项目问题）

- tauri 打 DMG 时 `bundle_dmg.sh` 内的 `grep` 被 shim 成 toybox grep，实际运行中报 "brackets not balanced" 假正则错误导致打包失败（隔离复现不出来，只在真实 attach 流程中触发）。且 WorkBuddy 环境会重置 PATH，无法用 PATH 覆盖回系统 grep。
- 解法：tauri build 失败后（.app 已生成），手动 `/usr/bin/sed -i '' 's| grep -E| /usr/bin/grep -E|g' bundle_dmg.sh`，再手动 `bash bundle_dmg.sh --skip-jenkins --volname "云小历" --app-drop-link 480 170 "云小历_0.1.3_aarch64.dmg" "../macos/云小历.app"`（--skip-jenkins 跳过需要 Finder 自动化权限的 AppleScript 装饰步骤，本环境没有该权限）。
- 失败的中间产物要清理：`hdiutil detach /Volumes/dmg.* -force` + 删 `bundle/macos/rw.*.dmg`。
- 用户自己在终端跑 `tauri build` 用的是真系统 grep，不会遇到此问题。
