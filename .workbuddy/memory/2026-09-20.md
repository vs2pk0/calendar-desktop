## macOS 打包记录

- `npm run tauri build` 产物：`src-tauri/target/release/bundle/dmg/云小历_0.1.3_aarch64.dmg`（Apple Silicon）。
- 坑 1：tauri CLI 会校验 npm 包与 Rust crate 的 major.minor 一致；全新 `npm install` 会把 `@tauri-apps/*` 拉到更新 minor 导致构建被拒。解决：`npm install @tauri-apps/api@2.10 @tauri-apps/plugin-sql@2.3 @tauri-apps/plugin-http@2.5` 对齐 Rust 侧（tauri 2.10.2）。
- 坑 2：DMG bundling 需要 hdiutil 挂载 /Volumes，沙箱内必失败；release 编译完成后，取消沙箱重跑一次即可完成打包（编译缓存复用，只跑 bundling）。

## 闪退修复（重要教训）

- 症状：DMG 安装后打开 0.5s 左右闪退（SIGABRT / rust panic）。
- 根因：`lib.rs` 中 `&wd[1..]` 对中文字符串按字节切片，"周"是 3 字节，触发 `slice_error_fail_rt` panic。崩溃点在托盘时钟线程第一次 tick（500ms），与"打开后闪退"吻合。
- 修复：星期文案改成两个完整数组（周日/星期日…），不再切片；`start_tray_clock` 循环体加 `catch_unwind` 兜底。
- 排查方法：`~/Library/Logs/DiagnosticReports/*.ips` 第二段 JSON 的 exception + faultingThread 帧可直接定位 Rust panic 符号。
- 教训：Rust 处理中文/多字节字符串禁止按字节硬切片，用完整字面量或 `chars()`。
- 验证：release 二进制与 DMG 内 App 均运行 6s+ 无崩溃。新 DMG 已覆盖产出。
